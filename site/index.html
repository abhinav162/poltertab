The problem

Headless browsers are logged out of everything.

Most browser automation spins up a fresh, empty browser. It has none of your cookies, none of your sessions — so it stops at the first login wall. You end up scripting logins, juggling credentials, or giving up on the pages that matter.

Headless automation logged out

  • Starts from a blank profile, every time
  • Hits login walls, CAPTCHAs, 2FA
  • You script and store credentials yourself
  • A separate browser from the one you use

PolterTab already in

  • Your real Chrome profile — already signed in
  • Cookies, sessions and logins are already there
  • No credentials to script or hand over
  • The exact browser you work in every day

How it works

Your agent talks to the browser you already have open.

A short, local chain. Nothing leaves your machine, and no new browser is launched.

01

Your AI agent

Claude Code, Claude Desktop, Cursor, or any custom MCP client.

02

MCP server

A local Node.js server speaks the Model Context Protocol over stdio.

03

PolterTab extension

Connects to the server over a local WebSocket and runs the commands.

04

Your Chrome

The extension acts in your real profile, using Chrome's own APIs and the DOM.

Security & privacy

It runs on your machine, and only your machine.

Driving your real, signed-in browser is powerful, so the design keeps control with you.

Local only

The server and extension run on your computer and talk over a local connection. There are no PolterTab servers and no account.

Uploads are opt-in

File uploads are refused unless you allowlist the folders they can come from. Nothing on disk is reachable by default.

Open source & verifiable

The code is public on GitHub and the npm package is published with provenance, so you can check exactly what you run.

Works with

Any MCP-compatible client.

PolterTab is a standard stdio MCP server. If your tool speaks the Model Context Protocol, it can drive the browser.

Install

Two steps. Requires Node 18 or newer.

1

Run the setup wizard

It installs the browser-navigation skill, adds a CLAUDE.md note, and registers the MCP server. Safe to re-run.

npx poltertab setup
2

Load the Chrome extension

  1. Download the latest release zip and unzip it.
  2. Open Chrome → chrome://extensions/
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and pick the chrome-extension/ folder.

Then restart your AI tool so it picks up the new browser tools.

FAQ

Questions

Does it launch a separate browser?

No. PolterTab drives the Chrome you already have open, with your existing profile and sessions. There is no headless browser and nothing to log into again.

Where does my data go?

Nowhere but your own machine. The MCP server and the extension run locally and talk over a local connection. There are no PolterTab servers and no account to create.

Can it read my files or upload them?

Only folders you explicitly allowlist. File uploads are refused by default, so the agent can't reach anything on disk until you permit it.

Can more than one agent use it at once?

Yes. Point several MCP clients at the same browser — the first server to claim the local port serves the extension, and the others proxy through it.

Which AI tools work with it?

Any MCP-compatible client: Claude Code, Claude Desktop, Cursor, or an agent you build yourself. The setup wizard targets Claude Code; other clients register PolterTab as a stdio command.

Is it open source?

Yes — the full source is on GitHub, and the npm package is published with provenance.
